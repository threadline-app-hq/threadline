# Threadline redesign plan

October5-12,2026. Goal: a distinctive photographic app, with clear tools and restrained, purposeful motion. All work uses free resources.

1. Reference study, visual critique, type and palette, brand mark.
2. Navigation, feed, profile and older-photo browsing.
3. Create and stories, crop behavior and touch controls.
4. Messages, activity, readable conversations and errors.
5. Responsive layouts, keyboard access, contrast and text scaling.
6. Regression tests, loading performance and storage behavior.
7. Final review of live screens and known limits.

A calendar plan does not prove a day's work complete. Keep checks tied to observable results. Preserve all existing functional protections as screens change. No copied brand assets or paid fonts.
